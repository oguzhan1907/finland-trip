# Urho Kekkonen National Park

Urho Kekkonen National Park is a North Lapland / Saariselka-area national park candidate. It matters because route sources keep North Lapland visible as a high-distinctiveness comparison route, but the current Helsinki -> [[Entities/Ruka]] -> Helsinki frame makes anything beyond Ruka a major pace decision.

For this trip, Urho Kekkonen is a **northern ambition marker** more than an active stop. It helps define what would happen if the trip pivoted toward Lapland, but it should not be casually added to the current Ruka plan.

## Planning Role

- Candidate only if North Lapland becomes a dominant priority.
- Useful comparison point for how far north the trip could go beyond Ruka.
- Strong hiking and wilderness identity, but likely too far for the current default route.
- Needs a full route reset, official rule checks, lodging/hut checks, and drive-time proof before becoming realistic.

## What It Could Add

- A true fell/wilderness Lapland component beyond the Ruka/Kuusamo anchor.
- A direct link to Saariselka / Inari-style northern planning.
- A clear benchmark for deciding whether "Lapland" is actually in scope or only a fantasy extension.

## Operational Checks

- Official Luontoon instructions and rules.
- Trailhead, parking, hut, camping, and weather-readiness requirements.
- Whether the route can absorb the long northbound and southbound driving stages.
- Whether any hikers have the gear, time, and comfort level for a real fell/wilderness stop.
- Whether adding this park would force dropping Saimaa, Hossa, Koli, or archipelago modules.
