# Lapland

Lapland is the high-distinctiveness northern route region that keeps appearing in route sources, but it is not currently the default for this trip beyond the [[Entities/Ruka]] / Kuusamo anchor. Lonely Planet's northbound itinerary reinforces the appeal of Rovaniemi, Inari, Kilpisjarvi, and wilderness routes while also showing the distance and time cost.

[[Entities/Urho Kekkonen National Park]] is the current national-park marker for this northern ambition. It helps define what a true Lapland pivot would cost, but it should not be added casually to the current route.

## Planning Role

- Candidate only if the user decides northern Lapland is a dominant priority.
- Useful as a contrast point when pruning over-ambitious route ideas.
- Should not be added casually to the existing Ruka plan without a major pace reset.
- Related national-park comparison page: [[Entities/Urho Kekkonen National Park]].
